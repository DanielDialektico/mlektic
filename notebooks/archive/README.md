# Archived notebooks

This directory preserves the project's earlier visual investigations.

- `phases/` contains the small, versioned notebooks delivered with earlier
  implementation phases. They retain Git history but are no longer the
  canonical human-QA matrix.
- `exploratory/` contains the original `test_*` and `Bocetos_*` notebooks with
  their embedded outputs. They are intentionally local and ignored because
  some exceed GitHub's file-size limit. Do not delete or clear them as part of
  normal cleanup.
- `archive_manifest.json` records the local exploratory files, byte sizes, and
  SHA-256 checksums. Regenerate it with
  `python scripts/inventory_archived_notebooks.py` after an intentional archive
  change.

Canonical, reviewable replacements live in `../qa/` and are generated by
`scripts/generate_notebooks.py`.
